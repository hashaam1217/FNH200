# FNH 200 Study Decks

Exam-prep material generated from the 13 lecture decks and podcast transcripts.
**454 flashcards · 157 cloze cards · 193 practice MCQs** in the instructor's exam style
(A–E options, "all/none of the above," (i)–(v) combinations, real course confusables as distractors).

## Files

- `anki-flashcards.tsv` — all 454 basic cards, tagged `FNH200::LessonNN`
- `anki-cloze.tsv` — all 157 cloze cards, same tags
- `lesson-01.md` … `lesson-13.md` — readable per-lesson decks: flashcard table + cloze facts + MCQs with answers and explanations

## Importing into Anki

1. **Basic cards:** File → Import → `anki-flashcards.tsv`. Note type **Basic**, fields
   Front / Back / Tags (set the third field to "Tags" in the import dialog), separator **Tab**,
   and check **Allow HTML in fields** (cards use `<br>`).
2. **Cloze cards:** File → Import → `anki-cloze.tsv`. Note type **Cloze**, fields
   Text / Tags, separator Tab, Allow HTML.
3. Study by lesson via the tag browser (`FNH200::Lesson06` etc.).

## Known source discrepancies (both answers defensible — know the context)

- **Solanine "normal" level:** Lesson 12's slide says **2–13 mg/100 g**; Lesson 13's sample
  marking scheme says **4–6 mg/100 g**. The tested facts are the green-part level (80–100 mg),
  cholinesterase inhibition, and heat resistance.
- **Probiotic threshold:** the Lesson 13 slide says **1.0 × 10⁹ units per serving** for a claim;
  the Canvas lesson text says above 10⁶ per mL. Use 10⁹ per serving unless asked about the Canvas text.
- **Corn syrup sweetness ranking:** the instructor's own answer is *"tricky question — not enough
  info,"* even though Table 2.2 lists corn syrup at 50. Answer what she intended.
- **Lesson 11's learning objective labels niacin "(B2)"** (conventionally riboflavin); cards avoid
  asserting the number.
- One deck F-value MCQ (Lesson 6, tomato juice D = 5 min) has no self-consistent correct option;
  the decks' other worked example (D = 7 min → F = 0.0021 s) is used instead.
- Episode 4's podcast says the big-brand peaches were "Choice" — the deck labels Del Monte
  **Canada Fancy**. The testable point is that grade is independent of brand.
